## 先选你需要的通知

| 我想知道 | 使用什么 | 从哪里设置 |
| --- | --- | --- |
| 今天有哪些番播出 | 每日播报 | 插件配置中的「每日播报」 |
| 字幕组发布了新资源 | RSS 订阅 | `/sub 番名`，按提示选字幕组 |
| 下载器开始下载或下载完成 | Webhook | [下载器接入教程](webhook.md) |
| ani-rss 订阅清单或进度有变化 | ani-rss 同步 | [订阅同步教程](ani-rss.md) |

**加入追番清单不等于订阅 RSS。** `/追番` 后的选源提示需要回复序号，才会建立 RSS 订阅。
如果接入了 Webhook，并启用了追番会话联动，追着这部番的会话也能收到下载通知。

RSS 的“资源发布”和 Webhook 的“下载完成”是两件事，同时开启可能收到两份通知。
只想知道下载完成时，可以只用 Webhook，并在下载器中选择相应事件。

## 每日新番播报

1. 在 AstrBot 插件配置或我的番剧管理页中开启 `push_enabled`。
2. 设置 `push_time`，例如 `08:30`。使用 **AstrBot 所在机器的本地时区**。
3. 到目标群发送 `/日历订阅 开`，或在管理页「播报」中填写目标会话。

不想再接收时，在群里发送 `/日历订阅 关`。如果该群也被管理员填进固定目标，还需要从固定名单中移除。

打开 `push_only_watchlist` 后，每日播报只列出目标会话追番表里的番；清单为空就不发。
这个开关只影响每日播报，不限制 RSS、Webhook，也不限制手动查询 `/今日新番`。
评分与在看人数筛选可以保持默认；设得过高可能漏掉刚开播、还没有评分的番。

### 为什么有些番不在今日卡片里

- 未到首播日期或已确认完结的番不列出，**最终话当天仍保留**。
- 主栏使用 Bangumi 每日放送候选，并核对首播、结束日期和分集资料。
- 「跨季续播」补充日历遗漏但有在播证据的作品，不代表全是年番。没有结束日期不等于仍在播；资料不足的补充条目暂不显示。
- 网络故障时主栏会保留无法核验的官方候选。上游资料不完整或日期有误时，结果仍可能不准确。
- 放送日按日本时间归组，与定时任务使用的服务器时区是两回事。

观看或下载进度达到总集数，不会被用来判断一部番是否已经官方完结。

## 通知发到哪里

「会话」指一个群聊或私聊。推荐从管理页提供的会话列表选择，手填格式见 [配置参考](configuration.md#怎样填写通知目标)。

| 通知 | 目标规则 |
| --- | --- |
| 每日播报 | `push_targets` 固定名单，加上用 `/日历订阅 开` 订阅的会话 |
| RSS 更新 | 建立订阅的会话；可用 `/sub_session` 改投到另一会话 |
| 下载器 Webhook | 优先使用 `webhook_targets`，留空则沿用 `push_targets`；开启 `webhook_notify_watchers` 时，加上追着该番的会话 |
| ani-rss 同步报告 | `anirss_sync_targets` 指定的会话；手动同步的行为见 [同步教程](ani-rss.md) |

**想让下载通知严格只进一个群：** 在 `webhook_targets` 中只填那个群，并关闭 `webhook_notify_watchers`。
每日播报的自助订阅名单不会自动成为 Webhook 固定目标。

## 通知里的链接

开启「附带文本链接」（`show_watch_text`，默认开）后，RSS 和下载器通知会在卡片外附上可点击文本。能确认是同一部番、同一季时补充观看入口；Bangumi 和资源详情列在「相关链接」，不当成播放地址。图片内不显示网址或链接按钮。

找不到观看入口或查询超时时，照常发送通知并保留已有资源链接。未绑定番剧的资讯类 RSS 不会按源名猜作品。入口可能受地区或会员限制，下载完成也不代表所有网站已经同步更新。关闭自动链接后，仍可用 `/在线观看 番名` 主动查询。

## 推送卡片的作品资料

单部番的 RSS 更新和下载器 Webhook 卡片会附上 Bangumi 的作品简介、核心制作信息，以及主角的名字、声优和简短介绍。

- 在管理页「配置 → 卡片与渲染」调整 **推送卡片主角人数上限**（`notify_character_limit`）：默认 3 人，可填 0~6，填 0 隐藏角色区。
- 只显示 Bangumi 标为「主角」的人物，不用配角凑数。简介最多 220 字，角色介绍摘取首段、最多 90 字；上游介绍可能含剧透，介意时可以关闭角色区。
- 资料缺失就省略对应内容，不编造介绍。查询失败照常发通知，角色接口故障也不影响已经拿到的简介和制作信息。
- 角色介绍保留资料原文；Bangumi 只有日文介绍时会显示日文，不额外调用模型翻译。
- 每日新番列表、批量同步摘要和未关联番剧的资讯 RSS 不展开人物资料，避免长图刷屏。
- 关闭「附带文本链接」只隐藏链接，不隐藏作品资料；纯文字或图片渲染回退也会保留查到的资料。

## 使用 AstrBot 人格

每日播报、RSS 更新和 Webhook 通知可以让 Bot 按自己的人格说一句话，再附上信息卡片。

- `persona_reply_enabled` 控制是否启用，默认开启；需要在 AstrBot 中配好人格和模型供应商。
- `persona_id` 和 `persona_provider_id` 留空时，跟随目标会话的人格与供应商；也可以指定。
- `persona_instruction` 只写转述要求，不用重复填写人设。
- `persona_max_chars` 限制转述长度，默认 180 字。
- 人格调用失败后间隔 1.5 秒重试一次；仍失败时，`persona_fallback_line` 决定是否用固定文案补上播报内容。

人格不可用时仍会继续发送通知，不要求你为了接收更新额外购买模型服务。
完整配置见 [人格转述](configuration.md#人格转述)。

## 自动更新追番进度

RSS 成功推送后可通过 `rss_auto_progress` 更新已有追番记录；Webhook 下载完成或整理入库后由 `webhook_auto_progress` 控制。
`webhook_auto_watch` 则控制是否给固定目标自动补上尚未追的番。它们是独立开关。

自动回填会保留更高的已有进度，不会因补下旧集而倒退，但**下载到第几集不等于实际看到了第几集**。
如果只想手动记录观看进度，请关闭相关自动回填；ani-rss 同步写入追番表也会更新进度，不需要时不要开启或导入。

RSS 的匹配边界见 [RSS 订阅](rss.md#推送顺手回填追番进度)，下载器的编号含义见 [Webhook 接入](webhook.md#3-ani-rss-里怎么填)。
